◆ CPDF_SetDocumentAIModel()

PDFSOLID_DECL CSDKErrorCode CSDK_PDFSOLID_CALL CPDF_SetDocumentAIModel ( PDFSOLID_STRING  model_path,
int  gpu_id 
)

Merges DocumentAI components from a model package used for advanced processing like OCR.

Precondition
Stop new SDK calls and join all active conversion/inference callers before configuring or reloading models; lifecycle calls must be serialized.

Each call loads only the capabilities contained in the given model package and merges them with the capabilities already loaded; it does not replace them. If a package fails to load, the capabilities loaded before are kept.

Parameters
[in]model_pathPath to the model package file, e.g. "documentai.model".
[in]gpu_idIndex of the GPU used by the AI model. -1 disables GPU.
Returns
CSDKErrorCode indicating the success or failure of loading the model package. e_CErrInvalidArg if model_path is empty; e_CErrConverting while conversion tasks are running or a release is pending.
