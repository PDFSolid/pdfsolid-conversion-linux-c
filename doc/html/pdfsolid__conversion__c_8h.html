PDFSOLID_DECL CSDKErrorCode CSDK_PDFSOLID_CALL CPDF_StartWordToPDF ( PDFSOLID_STRING  file_path,
PDFSOLID_STRING  output_path,
CConvertOption  options,
CConvertCallback *  callback,
char *  diagnostics 
)

Starts the conversion of a Word document to a PDF file.

Parameters
[in]file_pathPath to the input Word document.
[in]output_pathPath where the converted PDF file will be saved.
[in]optionsCConvertOption settings for conversion; start from CPDF_CONVERT_OPTION_DEFAULT. Word to PDF uses page_ranges and word_pdf_bookmark_mode; the other fields do not apply.
[in]callbackOptional CConvertCallback function for handling convert operations.
[out]diagnosticsOptional caller-owned buffer of CPDF_WORD_TO_PDF_DIAGNOSTICS_SIZE bytes. The buffer receives UTF-8 diagnostics and is not allocated or freed by the SDK. Pass NULL if diagnostics are not needed.
Returns
CSDKErrorCode indicating the success or failure of the operation. e_CErrUnsupportedFeature if the document uses features that may affect fidelity; the PDF is usually still produced, and the first diagnostics line is "output=produced" or "output=not_produced". e_CErrOutOfMemory if the diagnostics buffer cannot hold the complete diagnostics.
